The repository includes a GitHub quality workflow backed by explicit
capabilities and pre-commit for
consistent code quality:

- **Automatic validation** on pull requests and pushes
- **Language-agnostic linting** for Markdown, YAML, JSON, XML, and EditorConfig
- **Root language-specific checks** from generated `.pre-commit-config.yaml` aligned with the selected tooling template
- **Monorepo language configs** in generated `.pre-commit/languages/*.yaml` for explicit per-project language hook sets
- **Local quality checks** via `make quality` using the selected provider: `micromamba`, `mise`, or `system`

Provider-aware helpers generated by bootstrap:

- `.github/bootstrap-provider.yml` — explicit provider/language marker for tooling and AI agents
- `scripts/provider-run.sh` — run direct commands in the selected provider environment

## AI token optimization

Generated repositories include default token optimization for Claude Code,
GitHub Copilot, VS Code MCP, and ToolHive.

Included files:

- `tokopt.yaml` — shared token optimization defaults
- `tokf/` — user, profile, file, diff, log, JSON, MCP, and output filters
- `scripts/tokf-*` — token-safe helpers for diffs, logs, JSON, repo packs, and tool checks
- `.github/instructions/token-optimization.instructions.md` — agent-wide token policy
- `.github/skills/token-optimization/SKILL.md` — canonical shared token optimization skill
- `.github/mcp.json` and `.vscode/mcp.json` — ToolHive vMCP endpoint config
- `.claude/settings.json` — Claude Code MCP defaults

Claude PR review is optional. Install the Claude GitHub App and configure
Anthropic Workload Identity Federation with repository variables
`ANTHROPIC_FEDERATION_RULE_ID`, `ANTHROPIC_ORGANIZATION_ID`, and
`ANTHROPIC_SERVICE_ACCOUNT_ID`; the generated workflow uses GitHub OIDC and
does not require an API-key or OAuth-token secret. Comment `@claude` on a PR
to request a review.

The generated repository also includes an optional
`Request CodeRabbit Review` workflow. Run it manually with a PR number when a
Dependabot or other automation-authored PR needs an explicit
`@coderabbitai review` request.

Dependabot and release-please PRs can use the generated
`.github/workflows/classify-maintenance-pr.yml` workflow. It applies the
maintenance lifecycle labels only to same-repository automation PRs, while
preserving `autorelease: pending` and dependency labels. The separate Writer
and Reviewer App credentials must be configured in the protected
`production-maintenance` environment; labels never bypass required checks or
repository rulesets.
